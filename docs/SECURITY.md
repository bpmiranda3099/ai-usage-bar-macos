# Security Policy

## Supported versions

No releases are tagged. Only the latest commit on `main` is supported.

## Reporting a vulnerability

Do not open a public issue. Use the "Report a vulnerability" button on the repository's Security tab to send a private report. Include the commit you tested, steps to reproduce, and the impact.

## Disclosure

Reports are handled by the maintainer on a best-effort basis. Please allow time for a fix before disclosing publicly.
